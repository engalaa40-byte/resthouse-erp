# Resthouse ERP — نظام إدارة استراحة وشاليهات

تطبيق ويب في ملف واحد (HTML + CSS + JS، بدون بناء وبدون اعتماديات): حجوزات، ليالي بأسعارها،
أقسام، فواتير بالضريبة، عقد إستجار قابل للطباعة، لوحة حالة، تقارير وإيرادات لكل كيان،
مواسم، صلاحيات لكل موظف، ونسخ احتياطي.

- الواجهة عربية RTL، ويخدم الملف مباشرة من GitHub Pages.
- لا تُخزَّن أي بيانات على هذا المستودع ولا على GitHub: بيانات كل جهاز تبقى في متصفحه،
  ومَن يربط المزامنة يربطها بقاعدة Firebase الخاصة به من داخل الإعدادات.
- كلمات مرور الموظفين لا تغادر الجهاز أبداً، ولا تُرفع إلى أي سحابة.
- الإرسال إلى واتساب يفتح محادثة على جهاز الموظف نفسه (تطبيق أو متصفح) — لا خادم وسيط.

## التشغيل

افتح الرابط المنشور من أي متصفح على كمبيوتر أو تابلت أو جوال، أو نزّل `index.html`
وافتحه محلياً بدون إنترنت.

## تحديث النسخة

استبدل `index.html` بملف النسخة الجديدة من نفس المسار؛ لا حاجة لأي أمر بناء.
